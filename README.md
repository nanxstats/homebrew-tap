# Nanxstats Tap

## How do I install these formulae?

`brew install nanxstats/tap/<formula>`

Or `brew tap nanxstats/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "nanxstats/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
